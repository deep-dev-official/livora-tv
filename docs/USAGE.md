## 1. VLC Media Player (Desktop / Mobile)
1. Open VLC Media Player.
2. Go to **Media** > **Open Network Stream** (or press `Ctrl + N` / `Cmd + N`).
3. Paste any Livora TV M3U link above into the URL field.
4. Click **Play**. Open playlist view (`Ctrl + L` / `Cmd + P`) to search channels.

## 2. TiviMate IPTV Player (Android TV / Firestick)
1. Open TiviMate.
2. Select **Add Playlist** > **M3U Playlist**.
3. Choose **Enter URL** and paste your desired Livora TV playlist link.
4. Set update interval to **12 Hours** (aligning with Livora TV's validation cycle).
5. Click **Done**.

## 3. OTT Navigator (Android / Android TV)
1. Open OTT Navigator.
2. Go to **Settings** > **Provider** > **Add Provider**.
3. Select **M3U Playlist**.
4. Enter playlist URL and click **Apply**.

## 4. Kodi
1. Install and enable the **PVR IPTV Simple Client** add-on.
2. Go to add-on configuration > **General** tab.
3. Set **Location** to *Remote Path (Internet address)*.
4. Set **M3U Play List URL** to your preferred Livora TV M3U link.
5. Restart Kodi.
